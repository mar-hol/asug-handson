# Hands-on Lab: Connect Your Own Agent to SAP Joule via A2A

**Event.** ASUG Tech Connect (North American TechEd Tour stop)
**Format.** 2-hour hands-on lab
**Topics.** Architecture Center, A2A, North Star, AI Golden Path

## Abstract

This lab gives architects a clear view of SAP's enterprise AI reference architecture. It walks through the main layers and how they work together to run AI that is secure, controlled and reliable at scale.

The lab connects three parts. The North Star sets the vision for the Autonomous Enterprise. The AI Golden Path shows the path for building AI on SAP. The SAP Architecture Center provides the reference architecture that turns the vision into a working blueprint. In the hands-on part, a custom AI agent connects to SAP Joule through the open A2A agent-to-agent protocol.

A pre-configured repository keeps the focus on the architecture, not the setup. Attendees connect an agent to Joule instead of preparing tools.

## 3 Key Takeaways

1. **Know the main layers.** See how the SAP Business AI Platform, the Agent Gateway, agent identity and control layers work together to run AI agents safely and at scale.

2. **Build and connect your own agent.** Connect a custom AI agent to SAP Joule using the open A2A protocol, following the Bring Your Own Agent path. Watch how the Agent Gateway controls and secures the agent's calls into the enterprise.

3. **Take the reference architecture with you.** Use the SAP Architecture Center to build agent-based architectures on SAP, from the North Star vision through the AI Golden Path to running code.

## How This Aligns to the SAP Headless Strategy 
The SAP headless strategy separates core SAP business logic from the user interface. This lets teams deliver experiences across any channel, including web, mobile, IoT and AI agents, without being tied to a traditional SAP UI.

An agent connected to Joule through A2A works as a headless user of SAP. The agent reaches SAP business features over an open protocol with no SAP screen involved. The agent becomes a new channel into the enterprise, controlled and secure. This lab shows the headless strategy at work, where an agent built on its own talks to SAP over an open standard and delivers results without a UI.
